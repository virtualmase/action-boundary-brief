# Security policy

Do not publish secrets, credentials, personal data, customer information, vulnerability details, or live incident records in this repository or its issue tracker.

This repository is a static template and documentation project. It does not accept user input, operate external tools, retain records, or make authorization decisions. If you identify a security concern in its source, use GitHub’s private vulnerability-reporting mechanism when available, or contact the repository owner through a private channel. Do not open a public issue with exploit instructions or sensitive details.
